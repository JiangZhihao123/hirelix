# 猎头连续工作过程复查（2026-10-11）

## 结论与范围

延续两份简历、两个 JD 的一周工作记录，在真实 Chrome 中继续做通话准备、记下新通话、协调面试、查看及缩短客户报告、检查分享权限和安排工作优先级。使用虚构招聘资料、本地独立 QA PostgreSQL、真实 DeepSeek 与独立 worker；没有生产部署、外部发送或付费人才召回。

原先“能连续跑完”不足以说明使用过程合理。本轮发现了界面上下文与 Agent 不一致的明确错误，也发现重复询问、过量检索、过度推断工作状态等体验问题。

## 实际发现及修改

1. **打开 Cedar 报告，Agent 却分析 Owen 评估。** 原来只有显式修改按钮传递文档 ID，资料面板的选择不进入 runtime。现在候选人、职位、记录、文档和文件选择作为每条消息的上下文发送，服务端校验所有权并读取名称与版本。编辑目标可以来自同一账号的其他对话，不再限制创建对话。输入框显示 Discussing / Revising，可清除；选择本身不授权写入。
2. **修改保存后右侧仍可能停留在旧内容。** 复用现有 work/document change 事件刷新面板，不增加第二套状态或工作流。修改回执压缩为 Updated · Previous version kept，面板不再重复两个长标题。
3. **临近通话却重复确认已知条件。** 补充 recruiting-records Skill：围绕尚未解决的问题准备少量可直接使用的话题；已确认的薪资、到岗、办公及权限不默认重问；客户才能回答的问题交给客户。新通话成功保留为单独记录，面试可用时间没有被写成已约面试；可复制的短消息直接交付在对话中。
4. **简单任务读取整组长文档。** read_role 改为文档索引，按需 read_document；runtime 要求按缺失证据选择最小必要工具，避免无变化的重复读取。方法仍在 Skill 中，没有为 Cedar、Beacon 或一周日程编写分支。
5. **已约好被当成已准备好，时间段被当成截止期。** Skill 区分可用时间、已约安排、已完成工作；提醒准备面试也可能是下一步；依赖只阻塞相关动作，不代表整个委托无事可做。草稿、没有发送回执和实际从未发送也不能画等号。
6. **正文里的 draft 被生成成链接地址。** UI 不再把无协议、非站内绝对路径的裸词渲染成可点击地址。真实 DOM 验证原有错误回复的 `a[href="draft"]` 数量为零；这是阻止无效导航，不代表模型从此不会写错链接。
7. **报告已保存，却被 Agent 说成缩短失败。** 真实保存是 v2 约 480 词到 v3 220 词；模型受先前错误回复影响，连续误判。read_document 现在提供实际英文空白分词数和最多五个历史版本的精简长度摘要，沿用现有版本表并按用户隔离。runtime 明确当前保存结果优先于旧回复。随后真实对话正确承认缩短已保存。

## 验证证据

- Chrome：候选人面板选中 Owen 后，查询 Cedar 分享权限，正确指出现有权限仅限 Beacon；没有写入新的权限。
- Chrome：选中 Cedar 报告并要求缩短，保存为 v3；Maya 推荐仍 v3、Beacon 报告仍 v2、Owen 评估仍 v1。
- Chrome：通话后的可用时段被记录，直接返回可复制客户消息，没有创建不必要的文档或邮件发送任务。
- 真实 AI / PostgreSQL 回归：当前选择覆盖旧对话文档、拒绝跨用户选择、精简不超过 45 词、其他文档不变。最终单测链路通过；与一周连续记录相关的四项真实回归均通过，另三项原有 assistant-work 回归通过。
- 本地单元回归：367 项，365 通过、2 项原有跳过、0 失败。变更文件 ESLint、TypeScript 和生产构建通过。
- 首次新文档回归曾因不合理的短输入与过量检索出现模型输出上限失败；保留失败日志，修正输入并收紧检索后重跑通过，没有将首次失败记作成功。
- 原始截图、工具轨迹、独立数据库回读及日志位于忽略目录 `output/recruiter-process-review-20261011/`。截图 `wrong-document-context.png` 记录原始错误，`selected-report-verified.png` 记录版本证据纠正后的真实界面。

## 尚不能宣称的结论

本轮修复了可复现的上下文与 UI 问题，但不能据此宣称所有自然语言决策稳定。模型在复查中仍出现绝对化措辞，且可能单独调用命名工具增加一轮延迟；Skill/提示约束不等于确定性保证。这里记录的是本地真实链路，不能替代生产验收或无限场景的自然度保证。

最终新对话正确优先建议 Cedar 确认时段、Beacon 准备面试，没有再把草稿称为可直接发送；但仍说了“Nothing else on Cedar moves until that's set”，将预约依赖过度扩大到整个委托。因此优先级建议的措辞稳定性仍未通过严格验收。没有为屏蔽这句话添加关键词过滤或案例分支。
