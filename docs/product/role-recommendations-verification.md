# 职位推荐实施与验收（2026-10-14）

推荐总览以职位为行，复用现有职位详情、材料、分享快照、邮件回执和业务记录，没有新增数据表或固定工作流。职位内查看逐人反馈、交付历史和推荐材料。助理的 `read_role` 同时读取实际交付摘要；`record_delivery` 与界面复用外发记录服务。

交付区提供分享链接、Gmail、复制与下载。Gmail 支持在已核对正文中附上当前推荐链接，发送请求与发送快照一起去重。记录外部交付支持姓名、邮箱或其他联系人描述，多次实际交付分别留档；同一请求重试不重复记账。旧链接快照与后续草稿分别保存。发布、复制和下载均不改变推荐统计。

验证范围：

- 本地 PostgreSQL 集成：多人计数、并发幂等、重复请求冲突、独立反馈、租户隔离、旧分享快照、失败/未知 Gmail 回执不计入推荐、Gmail 回执与旧状态标记不重复统计。
- 现有分享反馈集成：逐人反馈、链接替换/撤销、拒绝分享权限校验。
- Chrome 已登录本地页面：职位总览、角色页签、推荐材料、Gmail 预览及链接组合、复制/下载入口。
- 真实 AI 测试：只记录用户报告的外部邮箱交付，保存时间、内容与推荐记录，验证没有创建发信记录。
- DOCX 从 Chrome 实际下载并核对两位候选人正文；复制按钮完成浏览器写入，自动化剪贴板读取接口未返回内容，跨邮箱粘贴效果尚未独立验证。
- 391 项单元测试通过，2 项原有跳过；TypeScript 检查通过，已跟踪源码 ESLint 无错误（1 项原有测试警告）。未跟踪的 `tmp/` 旧脚本有既存 lint 错误，不作为交付代码提交。

真实 Gmail 外发需要明确的收件人和发送授权，本轮没有发送邮件；数据库中的模拟回执仅验证状态处理，不能替代 Gmail 送达验收。分享链接沿用现有无登录访问与逐人反馈能力；Gmail 收件箱同步不在当前实现范围内。
