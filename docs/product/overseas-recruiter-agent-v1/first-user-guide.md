# Your first role in Hirelix

Hirelix is a personal AI agent for professional headhunters. It works with the candidates, briefs and notes you save, and helps you prepare material for your clients. You review changes and decide what to share.

1. Open [Hirelix](https://hirelix.online) and continue with Google. The first AI task starts a seven-day trial with 200 AI credits; no card is required and the trial does not turn into a paid subscription automatically.
2. In a new conversation, attach a candidate CSV, a readable PDF CV, or a DOCX CV and ask to import it. Keep each file within 4 MB. Review the preview before saving. For a possible duplicate, choose the existing person and review which fields to keep. Your original source and earlier saved versions remain available. Scanned PDFs need a readable text version.
3. Paste or attach a JD with its client name and ask the agent to prepare a role. Review the proposed requirements before saving. You can also create a role from **Roles**.
4. Ask the agent to compare named candidates against that role, or find relevant experience in your saved pool. Open the cited records and check missing evidence. A strong profile for one role does not establish suitability for another; interest, availability and permission need confirmation.
5. Add candidates to the role, then prepare a **Candidate submission**. Select the supporting notes and the exact CV for each person. Private notes and files are not selected automatically. Review and edit the draft; assistant revisions are proposals you accept before they replace it. PDF and DOCX exports contain the written recommendation. Download selected CVs separately and review them before sharing.
6. Save client feedback against the same role. If it changes the requirements, review the proposed update. Earlier materials keep the sources captured when they were prepared. For a **Search update**, choose the reporting period, check the displayed reporting timezone, and select relevant dated records; an undated note is not evidence that an event happened during that period.

7. To prepare recurring updates, open **Roles → your role → Activity → Set an agreement**. Choose weekly or fortnightly timing and an IANA timezone, select candidate profiles, and explicitly opt into dated role records or private candidate notes. Each completed draft uses AI credits and stays private until you review and share it yourself. The agreement shows the next actual time; daylight-saving changes follow the displayed local-clock policy. You can pause it, retry errors, and choose to receive an in-app notice only when the selected evidence changes. Setting an agreement currently happens on the role page.

Tasks continue in the background when you leave the page. Reopen the conversation or **Background tasks** to see the result. If a task fails, read its error and use its retry action. Failed work is not charged; retry reserves credits again and settles only its successful execution. Copying or exporting a submission does not send it or mark it submitted. Use **Record actual submission** only after you have actually shared it yourself.

The Personal Agent subscription costs USD 49 per month or USD 490 per year, plus applicable tax. It includes 3,000 AI credits each UTC calendar month, with no rollover. Check **Settings → Billing** for the current trial, allowance and subscription. Saved work stays readable when AI access ends.

Use **Export profile & records** on a candidate for your own archive. This includes private records, so inspect it before sharing. Account-level privacy or deletion requests go through the support link in **Settings**; they are handled manually after identity verification. See the [privacy policy](https://hirelix.online/privacy) and [terms](https://hirelix.online/terms).

Release note: this guide describes the intended first-user workflow. Current production acceptance and any blocking limitations are recorded in `docs/launch/production-readiness-2026-10-01.md`; the guide itself is not evidence that release gates passed.

AI credits vary with the services consumed, so longer or more complex work may use more. Billing shows used, available and reserved credits. Only completed work is charged; system retries, automatic indexing and follow-on imports are included.
