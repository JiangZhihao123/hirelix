# v1.2 实施与验收记录

目标：完整实现 `product-spec.md` 的首个可用版本，以及六张新版页面所对应的真实交互。此文件记录实际证据；未验证的项目保持未完成。

## 范围与顺序

1. 数据基础：候选人、独立职位、原始记录、候选人与职位关系、版本、交付物、持久任务。
2. 候选人：编辑、CSV/PDF/DOCX 导入与预览、合并、记录、删除/导出、覆盖旧资料的全库检索。
3. 职位：新建与编辑 JD、需求版本、关联人选、针对职位的判断、活动与反馈、暂停与恢复。
4. 交付：Submissions，Search update，生成/修订/版本/预览/复制/PDF/DOCX，真实提交与反馈记录。
5. 私人助理：对象上下文、来源、可审阅动作、历史会话、附件、失败恢复、定期草稿与通知。
6. 视觉与完整链路：新版导航、暖白/炭黑/深绿、响应式、键盘操作、真实 OAuth、实际模型与数据库、多状态连续截图。

按原文后续范围保留 O05 邮件发送和回复同步、日历连接、团队共享。当前任务不触发付费外部 sourcing，不执行生产部署。
