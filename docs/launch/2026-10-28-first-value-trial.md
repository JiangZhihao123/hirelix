# 海外独立猎头首次价值试用方案

状态：可审阅的试用准备，尚未招募、联系、收集数据或开展试用。上线和实际用户操作需要另行授权，并先完成发布门禁。本方案用于发现问题，不声称样本代表市场、证明留存或验证付费。

## 对象与招募条件

先邀请 5–8 位英语工作环境中的独立猎头或小型机构顾问，覆盖至少两种历史资料来源和不同业务岗位；筛选条件是近期确实需要从已有候选人资料寻找或比较人选，能自行提供有权使用的资料，并愿意在首次体验与后续一周内反馈。人数不足时如实报告，不用内部账号补充。为避免要求交出真实个人资料，可先用用户自有且已脱敏的少量资料或虚构资料；真实资料只在受邀人确认其使用权限、产品部署就绪且已有明确收集授权后使用。不得替受邀人访问其 ATS 或邮箱。

## 试用任务

研究员先说明这是个人 Agent 的自然对话，让参与者自行表达目标；不预设工具调用或让其遵循导入向导。记录其原始任务意图的脱敏摘要和实际完成情况，必要时仅提供产品基本操作帮助，并注明研究员介入。

1. **整理历史资料**：让参与者提交一小份候选人表格和可选的原件/备注，并用自己的话授权整理。观察是否理解哪些内容会保存、哪些有冲突或未处理；从实际回执和资料页面核对已保存数量、来源和原件，不要求处理无权使用的资料。
2. **用现有资料完成新工作**：让参与者提供一个其正在处理的 JD 或脱敏 JD，请 Agent 在刚保存的资料中找出值得进一步了解的人并说明依据与不确定点。记录找回、证据可读性、漏项或错误，以及用户能否决定下一步；若资料不足，允许合理地提出问题或报告缺口。
3. **形成内部成果**：让参与者按自己的需要请求比较或内部简报，打开已保存成果，检查人选、来源、事实与不确定点。未经明确另行授权，不发邮件、不发布分享链接、不更新用户未要求修改的资料。
4. **稍后续接**：首次结束后约 2–7 天，在参与者自愿回来时让其继续同一项真实工作或更正一条信息。只记录实际发生的回访和工作结果；未到观察时间或未回应不计作已流失。

## 判断与停止条件

逐人记录四项状态：完成、部分完成、未完成或不适用，以及研究员是否介入。首次价值的定性通过标准是：用户能找到并核对至少一项与 JD 有关的既有证据，理解关键缺口，并认为结果足以支持一个具体的下一步；仅出现搜索结果、保存文档或页面打开不能代替用户判断。以实际样本逐一报告通过与失败及分母，不提前把 5–8 人换算成可靠的市场转化率。

出现跨用户资料、未经授权业务写入或外发、来源/原件丢失、伪造事实且无法立即辨识等情况立即停止该参与者测试并保留脱敏故障证据；待根因修复及针对性回归后才继续。普通模型回答不满意单独记录，不直接判成工程故障。支付、传播和持续留存只能根据后续真实行为观察，不能从首次完成率推断。

## 访谈与最少记录

首次完成后询问：

- 你原本用什么方法找回这些人，最费时的环节是什么？
- 哪一条结果或来源帮助了你作下一步决定？哪些结论不可信或缺少信息？
- 保存范围、未处理项目和下一步操作是否清楚？哪里需要研究员帮助？
- 在什么真实任务中你会再次打开它？你还需要什么证据才会使用结果？

回访时询问实际回来做了什么、是否继续上次工作、结果是否进入自己的工作和未回来的原因（如愿意回答）。最少记录试用随机编号、招募条件是否满足、所用资料类型和数量、任务开始/完成时间、实际状态、严重故障类别、用户对可用性的回答和自愿回访时间。研究记录不复制姓名、联系方式、简历、备注、JD 正文、邮件正文或登录凭据；任何需要保存的访谈原话先征得参与者同意并脱敏。

现有第一方看板可分别显示注册、保存候选人、候选人检索（含空结果）、多人文档、成果查看与符合观察窗口的 D1/D7 对话回访；这些是行为覆盖，不证明业务价值，浏览器事件可能缺失。按 [产品分析口径](../ops/product-analytics.md) 与访谈结果对照，保留未知，不补造事件。

## 启动前还需具备

明确上线授权和已验证的发布版本、招募与联络授权、可使用的测试材料/参与者同意、记录访问控制及试用负责人。未具备时保持本方案为准备材料，不联系客户、不建立外部问卷或向第三方上传资料。
