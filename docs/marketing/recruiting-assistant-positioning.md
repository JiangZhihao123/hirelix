# Hirelix：给独立猎头配一位助理

更新：2026-10-30。用户已确定并授权实施的新方向。本文是当前营销口径；旧推广记录、已发送邮件和历史方案保留原文，不能把它们当作新口径继续发送。

## 购买理由

独立猎头一个人承担客户、候选人、资料和交付。想请助理分担工作，却要考虑持续的人力开支。Hirelix 卖的是 **每月 $49 配一位 AI 猎头助理，把自己的时间腾出来**。

对外主张：**Your recruiting assistant. $49 a month.**

支撑句：You run the business. Let Hirelix organize the records, prepare client recommendations, and draft the follow-ups — so you have more time for clients, candidates, and closing placements.

功能是支撑这个购买理由的证据。接手一项工作、给出可用成果、利用已有资料继续干，体现助理的价值；注册、发出邀请或生成一段文字本身不能证明省时。核心受众继续是独立猎头与精品猎头顾问。独立律师是理解个体经营者需求的类比，本轮不扩展到法律服务，也不宣传未经验证的法律工作能力。

## 经济参照

首页直接并排展示美国行政助理工资参考 **约 $3,962/月** 与 **Hirelix $49/月**。来源为 [BLS Occupational Outlook Handbook, Pay](https://www.bls.gov/ooh/office-and-administrative-support/secretaries-and-administrative-assistants.htm#tab-5)：2025 年 5 月一般行政助理（不含法律、医疗和高管助理）年薪中位数 $47,540，除以 12 并四舍五入。2026-10-30 已读取官方原文。

这是一项透明的人力工资参照，不是猎头助理或离岸兼职助理的报价，不含雇主福利成本。页面不能把人力工资与软件差价写成每位客户必然获得的现金节省，也不宣称完整取代一个真人岗位。价格、试用与额度继续来自 `AGENT_PLAN`：$49/月或 $490/年，加适用税费；7 天 / 200 credits，无卡、不自动转付费；付费每月周期 3,000 credits。不能宣传无限工作量或未经验证的固定省时数字。

## 用什么证明助理价值

| 用户想甩掉的工作 | 展示的交办与成果 | 用户拿回的时间 |
| --- | --- | --- |
| 会后还要重新整理资料 | 给出简历与通话笔记，实际保存可继续使用的候选人记录 | 少做重复录入与翻找 |
| 每次沟通前重新读一遍背景 | 根据已保存的职位、候选人和反馈准备沟通要点与待核实问题 | 少做会前准备 |
| 客户催进展，还要从零写邮件 | 形成推荐、进展更新或跟进邮件，按用户要求修改并交付 | 少做文书整理 |
| 新职位又得重新解释客户要求 | 后续工作实际使用相关记录和显式偏好 | 少解释、少重做 |

内容先展示“原来这堆工作归我 → 我交代给助理 → 拿到什么成果”，再展示软件操作。制作资料不自动授权外发；定时提醒、报告和邮箱能力按当前真实范围描述。现有 35 秒虚构短片可作为一个任务示例，不冒充客户证言；之后的新演示以助理接手工作为主线。本轮不声称重制了视频。

## 营销执行顺序

1. 先统一首页、产品页、价格页、搜索摘要与分享图，让从任何入口进入的人都看到同一个购买理由和自助试用路径。
2. 自有内容与允许产品介绍的社区以“独立经营者的助理”切入。优先参与真实的工作负担、行政支持或准备客户材料的讨论，先给具体帮助，再透明披露创始人身份与相关入口。不继续扫目录。
3. 每条内容选择一个被助理接走的工作，展示实际可用成果。试用入口直接进入产品，不把预约演示、电话沟通、提供两份简历或向创始人发送候选人资料作为使用门槛。
4. 试用过程中帮用户完成他自己交办的工作。愿意提供反馈时，询问以往耗时、这次亲自投入的时间及成果是否可直接使用；将材料复杂度、模型耗时、返工时间和是否为内部样例一并记录。
5. 观察从内容到访问、注册、真实工作交付、付费、重复使用的变化。不同指标分别记录，归因使用现有 UTM；新文案可用 `utm_campaign=recruiting_assistant`，`utm_content=solo_desk` 或 `assistant_cost`。尚无客户数据时，不宣传“省 X 小时”或“已替代 X 位助理”。
