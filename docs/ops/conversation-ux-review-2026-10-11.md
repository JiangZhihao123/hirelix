# 2026-10-11 对话与成果查看体验检查

## 检查范围

在真实 Chrome 登录会话中查看正式站，从新对话、候选人页面返回、历史会话接续，到资料引用与推荐成果查看。使用现有虚构验收资料 Avery Moss / Fictional Willow，没有重新上传个人资料、生成业务记录、执行模型任务、发信、支付或对外分享。

修复在本地 Next.js 应用验收，通过正常 Google 登录，SSH 隧道连接真实 PostgreSQL，读取已有验收资料与原文件。未使用 API mock，也未部署或推送本轮代码。这是本地应用与真实资料链路的证据，不是正式站修复后验收，也不是全产品发布验收。

## 已修复

1. **对话中的推荐稿缺少简历附件入口。** 原来需要打开侧栏后再进入完整详情页，才能下载已选中的简历。现在对话交付卡、导出卡、资料侧栏和独立文档页共用 `DocumentAttachments`，按文档实际 `file_ids` 显示原件，提供打开与下载，并明确 Word/PDF 只包含推荐正文。继续复用原文件授权接口，不扩大读取权限。
2. **大量资料引用挤占回答区域。** 超过三条时使用原生可展开区域显示来源数量，三条及以下继续直接显示。所有原始来源仍可打开，正文内来源链接不变；长标题允许换行。
3. 补齐“已保存 · 尚未发送”和“已保存版本”的中文翻译。

功能提交：`5ef24cd`（附件入口），`b68313b`（引用区域）。
