# Agent 对话的连续执行与截图验收

2026-10-10。按用户指定的 Codex 对话交互方向实现；本次范围为本地修改与真实 Chrome 验收，尚未发布生产。

## 行为

- 首次发送后，新对话 ID 的 URL 同步沿用同一个视图。切换历史或新建另一段对话才重建视图；同步过程保留用户消息、输入焦点、附件与后续输入草稿。
- DeepSeek 的真实增量正文经既有 job.result 传到经认证的 SSE 接口。保留正文至最终消息事务保存，避免先清空预览再加载完整消息。只提取顶层 answer；字段顺序变化仍可提取，推理、动作与嵌套来源 JSON 不显示。
- 读取资料、检索等实际进度保存在已有 job.result.activity，完成时关联到所属消息；默认显示当前活动，可展开历史。停止的最后活动不会标为完成。
- 输入框旁可停止当前回复。执行中仍能输入新要求；“停止并发送”先调用原取消服务，再发送新要求。Enter 的行为在输入框旁明确说明，不新增队列或任务实体。
- 停止后的正文以未完成消息保存，刷新后可查看，重复停止不新增消息。停止和旧租约写入校验沿用原事务与租约机制。失败保留当前预览并标明未完成，仍可原地重试。
- 在底部跟随新内容，向上查看历史时保持位置；用户通过“回到最新”恢复跟随。

## 真实验证

本地 PostgreSQL `hirelix_workspace_qa_v3_review_20261008`、独立验收库 `hirelix_workspace_qa_turn_verify_20261010`、当前源码的独立 worker、真实 DeepSeek 与真实 Chrome。仅使用虚构验收请求，无外部发信、付费寻访或生产写入。

- Chrome 记录到正文从 168 字符增长至 4944 字符；32 次采样期间输入框底部固定、输入焦点保持，消息数量保持 4，最终转为已保存回复。
- 上翻期间正文从 1246 增长至 2346 字符、内容高度从 1259 增长至 1784，scrollTop 始终为 30.5，后续输入草稿保持不变。
- 浏览器实际停止、刷新、继续发送两句回答，以及执行中“停止并发送”一条更正要求均通过。数据库读回确认停止正文 2801 字符、状态 cancelled；更正后新回复 done，停止的旧执行未覆盖新消息。
- 独立真实模型测试在最终持久化前观察到 16 个不同正文快照；最终仅存一条正式回复。另验证有效租约、重复停止、迟到写入拒绝、失败重试与旧轮重试拒绝。队列与恢复集成 5 项通过，最终正文复验 1 项通过。
- 单元测试 358 通过、2 跳过；TypeScript、ESLint、隔离目录生产构建及 diff 检查通过。

证据保存在本地 `output/agent-turn-20261010/`：`02-streaming.jpg`、`03-streaming-growing.jpg`、`04-new-conversation-sent.jpg`、`05-reading-history.jpg`、`07-completed.jpg`、`08-correction-completed.jpg`、`browser-samples.json`、`scroll-samples.json`、`browser-db-proof.txt` 与各检查日志。截图已人工查看。

## 边界
