# 对话排版与个人记忆管理修复

2026-10-09，延续用户先部署验收、随后决定公开发布的范围。

- 新对话的滚动容器为 flex，消息及执行状态行原先仅有 max-width，在 auto margin 下按内容收缩，导致短中文气泡换行、状态居中。为这两类行设置可用宽度，保持气泡本身按内容收缩。
- 发送中隐藏输入框的重复文本，草稿状态与本地缓存仍保留以便失败恢复；保存成功但等待对话加载时标为 Sent，避免继续显示 Sending。避免重复的执行状态块，移除每条短消息都出现的保持页面打开提示。
- 记忆管理增加使用中/已忘记切换、搜索、偏好卡片、单条永久删除和清空全部。确认说明删除范围与不可恢复性，清空包括已忘记偏好及其版本历史；原聊天、简历、JD、提醒不删除，旧聊天仍可能包含原偏好内容。
- 删除 API 使用用户隔离、显式确认字段、与已有记忆写入相同的事务锁；单条删除检查版本和记录类型。不新增表或数据库迁移。
