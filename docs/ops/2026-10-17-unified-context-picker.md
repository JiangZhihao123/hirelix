# 职位与候选人统一引用选择器

## 行为

- 输入框内的 Link role / Link candidate 打开同一浮层，分别预选职位/候选人分类。浮层锚定输入框上沿，固定高度、结果内部滚动，内置搜索框、All / Roles / Candidates 切换、选中状态和 Done。
- 按钮打开或关闭不修改正文；允许跨搜索多选，每类最多 20 项，按类型与 ID 去重。引用标签可独立移除。
- 输入 `@` 默认搜索全部类型；正文继续输入即检索。选择后用名称替换当前 @ 查询，并建立引用。支持 Enter 选择、方向键导航、Escape 关闭。邮件地址不会触发。
- 搜索作用于当前用户整个资料库后截取候选项，不仅过滤已加载列表。候选人支持姓名、邮箱、职位和履历公司；职位支持名称、客户。空查询显示最近更新的记录。
- 多职位以 role_ids 提交，服务端校验所有对象归属、去重并保存 role_references。已有关联文档/详情页入口仍可提供原来的单对象上下文。引用只属于当前消息，不创建候选人与职位的业务关系。
- 当前及历史消息的多职位引用进入 Agent 上下文。明确询问全部已选对象时，不因 @ 插入正文的名称而缩小范围。
