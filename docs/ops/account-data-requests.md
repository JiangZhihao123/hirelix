# 账户数据请求

支持入口为 support@hirelix.online；账户级请求由支持人工处理，不是产品自助删除功能。账户导出工具只读数据库，不发邮件、不修改权限、不取消订阅、不删除数据。

## 先确认范围与身份

请求应来自账户邮箱。核对准确的 user.id 与邮箱；涉及邮箱变更或身份争议时先解决身份问题，不按姓名、候选人邮箱或账单联系人猜测账户。记录用户要求的是导出、更正、停止续费还是删除；这些动作不能相互替代。

## 导出

在私有运维环境加载现有 DATABASE_URL，使用一个尚不存在的私有输出文件：

```sh
node scripts/ops/export-account-data.mjs USER_ID ACCOUNT_EMAIL /private/path/account-export.json
```

脚本在 repeatable-read / read-only 事务中读取账户资料、工作区内容、原件、版本、用量、反馈、关联的历史搜索和能明确归属的统计/邀请记录。账户 ID 与邮箱必须同时匹配。原文件与反馈截图以 JSON 的 Buffer data 数组保存，可用 `Buffer.from(value.data)` 还原；导出后应逐个比对原件的 sha256。认证令牌、密码、旧人才服务 API key、分享令牌 hash 和 worker 租约 token 不导出。文件以 0600 权限独占创建，已有文件或符号链接不会被覆盖。

不把匿名访客按共享浏览器标识推断成此用户；不导出其他用户或公共人才缓存。Paddle、邮件提供商与受限备份不在该数据库文件中，支持须在回复里说明范围。交付前核对记录计数、文件原件及身份，将文件提供给已验证的请求人；本工具不授权发送或上传到新目的地。交付后按实际支持工单的保留需要处理临时导出，不能无限积累额外副本。

验证：2026-10-21，真实隔离 PostgreSQL 测试验证两用户隔离、原件字节、凭据排除、错误邮箱拒绝及失败后事务恢复。生产只读导出经批准的新测试账户：43 个数据组、3 份文件、4 位虚构候选人、4 个会话。临时文件位于 VPS 私有目录，未外发。

## 删除：当前审计发现与执行限制

2026-10-21 读取生产外键证明：只有 session、account、hirelix_product_feedback 直接级联到 `"user"`；大量 `hirelix_*.user_id` 没有该外键。**不得用 `DELETE FROM "user"` 冒充账户资料删除。**

实际请求需要覆盖：

1. 确认是否需要先交付导出，以及哪些账单记录因实际会计/法律义务继续受限保留；不将全量用户资料都当作账单保留。
2. 核对 Paddle 自动续费和待处理支付事件，独立处理取消；数据库删除不等于取消收费。
3. 停止该账号可能继续写入的会话、队列、提醒和邮箱动作，撤销会话与分享，确认执行中动作的结果；不能靠删除 jobs 隐藏已发送邮件。
4. 在可核对的维护窗口中按外键依赖从子记录到父记录清理精确归属的数据，包含无外键的版本、账本、用量、统计 metadata、邀请和历史搜索子记录。检查 OAuth 连接与原文件字节，不误删共享人才缓存或其他账户。
5. 删除后再次盘点归属记录、私有文件、分享和会话；记录实际保留的账单类别及备份轮换边界。已发出的外部邮件不会因数据库删除而撤回。

当前尚未完成上述删除过程的真实隔离库演练，因此账户删除处理不能记为验收通过。生产没有执行删除；该项列入发布收尾队列，不能以支持通知送达替代。
