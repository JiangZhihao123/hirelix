# 新对话首轮关闭思考

仅新对话第一条有效用户消息的第一个 Agent step 使用 DeepSeek `thinking.type=disabled`。同轮工具结果后的调用、后续用户消息和中断继续使用原环境配置；已保留执行记录的重试不再作为新对话首调用。无额外分类请求。标题生成原本已关闭思考，保持不变。

## 本地真实链路验证

2026-10-17，使用 `.env.local` 的本机隔离 PostgreSQL 和 `.env` 的真实 DeepSeek（请求模型 `deepseek-flash`）。通过真实 sendMessage、claimJob、assistantReply、finishJob 执行并读回已保存回复。未部署生产。

复现：`npx dotenv -e .env.local -e .env -- tsx scripts/debug/benchmark-first-message.ts`。脚本仅允许本机 QA 数据库，会创建测试会话并消耗真实模型额度。基线在请求边界恢复旧配置，其余使用相同 runtime；不替代模型响应。原始结果保存到 `tmp/first-message-benchmark.json`。

相同消息“你好”，交替顺序运行，每种配置 3 次：

| 指标（秒） | 原配置开启思考 | 首调用关闭思考 |
| --- | --- | --- |
| 首段正文，逐次 | 1.302 / 1.001 / 1.374 | 0.982 / 1.520 / 1.414 |
| 首段正文，中位数 | 1.302 | 1.414 |
| 整轮完成，逐次 | 1.645 / 2.247 / 2.539 | 1.123 / 2.366 / 1.992 |
| 整轮完成，中位数 | 2.247 | 1.992 |

首段正文从 HTTP 请求开始计时，不包含 reasoning；整轮从 sendMessage 开始至任务完成并读回结果，包含数据库操作和并行标题等待。直接领取指定任务，不包含 worker 轮询等待、浏览器渲染或生产网络延迟。两组同用本机代理；未清空提供商缓存，回复长度不完全相同，样本量小。

首段正文中位数增加 0.112 秒，整轮中位数减少 0.255 秒（约 11%）。没有证明首段正文稳定变快，不能宣称显著提速。一次标题生成未得到结构化结果，按现有逻辑保留原标题，正文成功。

真实工具用例“读取我保存的个人偏好，并简要告诉我有哪些”：两次模型请求依次为 disabled / enabled；实际读取空偏好并保存回复成功。同会话后续“谢谢”为 enabled，验证恢复原配置。

回归：437 项单元测试通过、4 项跳过、0 失败；包括 SDK 请求体验证首调用关闭、后续恢复、原配置已关闭时保持关闭、非官方提供商不覆盖。TypeScript 和变更源文件 ESLint 通过。此处 SDK 测试是 mock regression；上述测速和工具用例是 local real chain，未执行浏览器或生产链路验收。
