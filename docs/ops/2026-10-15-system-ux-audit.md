## 本轮修复

1. **Gmail 回跳参数**：带锚点的相对 callback 被 Better Auth 拒绝。改为校验同源后的绝对 URL，保留推荐交付区锚点；未放宽认证源或安全检查。
2. **邮件预览顺序**：Agent 工具准备邮件时不再单独插入一条提前出现的助手回复，而是将邮件元数据合并到当前轮的持久化执行回执。直接确认路径仍保留原有回复方式。
3. **失败改稿误丢旧预览**：只有成功准备新邮件或明确取消才替代旧预览；收件人无效等准备失败保留上一份有效预览。
4. **经历搜索可读性**：解析嵌套经历和记录文本，优先显示原始证据，不重复姓名/地点充当摘要；无法解读的分块继续保留查看原文入口。空结果说明匹配当前搜索模式。
5. **手动交付选项**：仅 Gmail 模式显示“附上所选 CV”，避免复制正文时让用户误以为附件也会进入剪贴板；手动发送仍可下载材料包。
6. **自然交互与文案**：指导模型减少内部字段、版本和修复过程的叙述，检查当前提醒/交付状态后再陈述；关系字段明确 JSON null 保留、空字符串清除。修正多个页面的英文单复数。
7. **额度回归用例**：旧测试用空 payload 创建聊天任务，已不符合当前队列领取条件；同时无目标的领取会误取遗留测试任务。改为正常创建对话任务、按 owner/job 领取，继续走真实模型、额度上下文与完成/失败结算服务。未修改生产计费规则。

模型表现仍有波动：最后一次“两点建议”的回答正确给出两点，但附加了一句时间安排提示。不能据此声称所有回答已完全简洁；本轮没有为虚构人物或具体案例加入硬编码分支。
