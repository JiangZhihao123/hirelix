# Agent 通用能力重构与本地验收

日期：2026-10-27。范围是用户认可的 Tools、Skills 和系统提示词改造。主 Agent 负责契约、集成和验收；三个 GPT-6.1 Terra / max 子 Agent 分别负责隔离文件执行、通用批量业务写入、文档与定时委托。仅本地实施和提交；未 push、未部署、未操作生产数据。

## 实现边界

- 保留 AI SDK ToolLoopAgent。注册 37 个工具、7 个按需读取的 Skills；工作方法放在 Skill，系统提示词保留授权、证据、协作和完成原则。Skill 参考资料按需加载并带版本摘要。
- 合并重复的候选人/职位检索、邮件读取、定时委托和记录创建/更新入口。没有把减少工具数量当成减少业务能力。
- `write_file`、`bash` 和 `read_file(path)` 使用同一执行租约的临时工作区。Docker 中只挂载当前执行文件；无网络、应用凭据、宿主目录或 Docker socket。没有宿主机 Bash fallback。
- `save_records_batch` 接收有 SHA-256 的已保存 JSONL，复用单条写入服务。每 25 条形成一个事务批次；业务修改、逐行回执与进度一并提交。中断后保留已提交结果，不重做已提交行。身份冲突、无变化、失败和未处理分别报告。
- 文件格式解释和关联判断由主 Agent 完成，脚本用于明确的重复转换。撤回 Recruit CRM 专用解析与目录关联，移除旧导入向导、字段映射/审核 API 和独立候选表格解析器。真实平台样本保留为研究证据，不作为程序分支。
- `save_document` 保存主 Agent 已写好的内容，支持创建、局部修改和整体替换；无隐藏撰写模型。文档引用候选人不自动建立职位人选关系。单独的旧文档 job 不再由 worker 或 retry 执行；旧 HTTP 写入口委托到会话 Agent。
- 定时报告从真实用户消息保存委托和来源授权；到期在原会话运行同一个 Agent，限定对象、来源版本、报告周期和动作。等待回答、暂停及版本变化影响后续执行；只有实际文档回执才算完成。
- 公开寻访通过现有搜索/抓取工具及 public-sourcing Skill；未启用 Bright 或退休的付费召回链路。

## 验收发现与解释

- DeepSeek 对工具根参数要求显式 object；模型适配层现在保留原分支约束并声明已经隐含的 object 类型。实际 SDK 还会把 intersection 的各个对象分别设为 `additionalProperties:false`，使相邻分支的必填字段相互冲突。现在通过 SDK 的 JSON Schema 扩展接口传递 Zod 输入 Schema，保留原 Zod 验证及修复诊断。真实 SDK 输出的 37 个工具和 8 个组合工具正负样本已验证；无法在 JSON Schema 表达的自定义 refine 仍由 runtime 验证。
- 文件读取此前会用第二次模型结果覆盖已提取原文，现保留原始提取文本；视觉转录单独标明为模型输出。
- Bash 非零退出此前可能显示成功，现向模型和 UI 保留失败状态与实际 stdout/stderr。工作区文件读取与写操作串行，普通已保存文件读取仍可并行。
- worker 的停止信号现在传递到主 Agent 和嵌套调用；批量写入统一锁顺序，防止与停止操作互锁。
- 浏览器发现内部比较文档被迫先建立职位人选关系，以及既有文档不能补充结构化人选的问题；在所属文档服务修复，不要求模型绕过或让用户额外维护关系。
- 自然模型曾缩写虚构姓名、臆造应用域名，并把短文请求写得较长。工具收到的原文及回执可以核查。这些作为模型表现记录；恢复重写 Skill 时遗漏的通用“保留姓名及标识”原则，不添加测试姓名特例，不据此宣称模型判断问题全部解决。
- 独立审查曾运行具有全局领取行为的旧 parent-lease 测试，误领取同一隔离库的另一个旧 QA job `822c9cf6-81e0-44b8-a7c7-cebf84a55969` 并将其置为 error；已停止该测试，未改动生产或他人数据。此后使用 owner/id 限定的验证。

## 发布与运行限制

生产未验证、未放行。部署前需要在实际 worker 主机准备 Docker daemon 和 `hirelix-agent-sandbox:1` 镜像，并应用本次批量回执、索引和定时授权迁移。文件执行没有网络，公开检索走业务工具。

临时工作区的正常退出与中断会清理；进程强杀时依靠 keeper 有限存活释放临时字节，停止容器和 volume 的元数据仍可能需要运维清理。Docker 共用宿主内核，不能把此验证描述为完全隔离的虚拟机。大型导出、复杂平台的完整多实体备份与生产并发不在本次已证明范围。
