日期：2026-10-19。范围：本机隔离库 `hirelix_workspace_qa_release_20261019`、localhost:3000、真实 Chrome、真实 Agent worker 和 DeepSeek 公开搜索。

## 修改

在 Agent runtime 指导中明确：LinkedIn 限制完整主页的自动读取，链接仍可用于寻找其他公开职业资料；回复须自然解释限制，同时说明实际取得的信息与已完成的工作。若补充资料有用，邀请用户粘贴主页内容或直接提供多张截图。截图和简历不作为完成已有可做工作的前置条件，不增加固定回复模板、关键词路由或强制决策卡片。

细化已有 `recruiting-records` 方法，保持来源、未知信息与保存授权边界，并在现有 Skill 描述中体现链接资料整理用途。没有增加产品 tool、抓取服务或业务流程。

验收中进一步明确：未命中搜索不能推断特定页面不被搜索引擎索引；解释与邀请应口语、适度简短。加强用户消息语言优先于 UI locale、工具描述和此前助手文字的指导。
