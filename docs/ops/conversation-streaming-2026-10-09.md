## 实现

- 普通消息等待只显示一行 Thinking；正文生成时显示正文及 Replying、Stop。移除发送、保存、启动等内部阶段的大块说明。
- 读取附件、查找候选人等实际工作进度放在默认折叠的 View activity 内；不新增任务中心。原有问题卡片、结果和错误恢复留在对话内。
- 官方 DeepSeek 使用 SSE，提取结构化回复首个 answer 字段的实际增量文本；推理、动作 JSON 不展示。复用现有 job.result.live_reply，以 450ms 节流写入；前端每次请求完成后间隔 750ms 查询已有任务接口，结束后刷新完整对话。
- 完整结构校验、权限检查和业务事务保持原有边界。停止、失败、重试、过期接管清理未完成正文，写入检查用户、运行状态及当前有效租约。无新增表或迁移。
- 保留原有规划模型调用，未承诺首字延迟固定或即时响应。OpenRouter 路径仍一次性交付完整回复；不模拟打字。流式预览是生成中内容，最终回复仍以校验及保存结果为准。
