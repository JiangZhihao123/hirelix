# Export references


Checked 2026-10-27 against vendor documentation. Menus and plan limits can change; use public research if current details matter. Help with the applicable product rather than listing every vendor or sending the recruiter through a generic migration questionnaire.

- **LinkedIn Recruiter:** Projects → Pipeline → select profiles → Save to CSV; profile PDFs are another option. Recruiter Lite does not support CSV exports. LinkedIn places selection and monthly download limits on these exports, and only recruiter-entered contact information is included in CSV. A personal LinkedIn account's connection archive is not an export of Recruiter projects, resumes or full recruiting history. [Official export documentation](https://www.linkedin.com/help/recruiter/answer/a412149). Applicant exports have a separate Export all to XLSX option and PDF ZIP support: [official applicant export](https://www.linkedin.com/help/recruiter/answer/a7459505).
- **Loxo:** An admin can select people across pages, then Export → Export selected, and receives a CSV by email. Its selected fields are included; resumes, attachments, activity-feed history, work history and education are not included in that CSV. The vendor restricts exports of Loxo Source-originated profiles. Do not promise all vendor-provided talent is portable. [Official export documentation](https://help.loxo.co/en/articles/1238814-export-people-and-company-records-from-loxo).
- **Recruit CRM:** The account owner on a paid plan can use Admin settings → Account → Data Export or Full Export. Data Export includes entity and association CSVs; Full Export also supplies attached files, with a separate download package. Candidate lists can be processed, but this is not proof that every notes, activity or assignment CSV can be faithfully reconstructed automatically. [Official full export documentation](https://help.recruitcrm.io/en/articles/3591116-exporting-all-data-for-recruit-crm-account-owners).
- **Recruiterflow:** Advanced Search → adjust filters → select candidates, including all results → Export to Excel → choose fields. It returns XLSX. Only the selected/filter-matching data is exported; resumes, attachments and notes are excluded and need separate provision. [Official export documentation](https://help.recruiterflow.com/en/articles/3671789-export-candidate-data-to-excel).
- **Crelate:** Contacts → Export → choose all records/all columns or a narrower scope. Its documentation describes Excel exports, with limits that may exceed one Hirelix import. Confirm that a contact list contains candidates rather than client contacts before saving it. [Official export documentation](https://help.crelate.com/en/articles/4120416-exporting-contact-data-to-excel).
- **Zoho Recruit:** An administrator can request a data backup under Setup → Data Administration → Data Backup. The data is CSV inside ZIP; a whole multi-module backup is not automatically a candidate-only archive. Notes and attachments have separate export mechanisms. [Official backup documentation](https://help.zoho.com/portal/en/kb/recruit/essentials/data-management/request-data-backup/articles/request-data-backup).
- **Manatal:** Admin table export includes the displayed columns and rows, so a page export is not necessarily the whole library. Admin Data Management → Data Export can export one dataset at a time to CSV or XLS; this feature may need vendor support to enable. Prefer CSV over unsupported XLS for Hirelix. [Table export](https://support.manatal.com/docs/export-function), [dataset export](https://support.manatal.com/docs/export-data).
