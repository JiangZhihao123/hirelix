# Public source access

LinkedIn restricts automated access to full profile details. A supplied URL alone is not proof that the whole page can be read. Search may reveal other public professional evidence; distinguish it from direct profile content and report only observed access/results. A failed search does not establish that a particular profile is private.

When additional material would help, the user can paste content or provide screenshots, including several images. This is optional enrichment of the existing goal, not a prerequisite, repeated demand or mandatory intake step. Do not invent an access attempt or bypass login or platform restrictions.
