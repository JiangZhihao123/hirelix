# Client document font

Noto Sans SC, SIL Open Font License (see OFL.txt).
Source: https://github.com/google/fonts/tree/main/ofl/notosanssc

NotoSansSC-Regular.ttf is a static weight 400 instance of the upstream
NotoSansSC[wght].ttf, generated with fontTools 4.66.0 varLib.instancer.
PDFs and DOCX files embed this TrueType font for portable CJK text.
